Tampilan

Sesuaikan suasana Luma. Glass menjaga panel berlapis; Solid mengurangi blur jika perangkat membutuhkan performa lebih.

Pengalaman mendengarkan

Saat antrean selesai, Luma dapat mencari lagu dengan artis atau genre yang berdekatan dari perpustakaanmu. Semua perhitungan dilakukan lokal.

Timer tidur

Hentikan pemutaran setelah durasi tertentu atau ketika lagu aktif selesai.

Timer tidur mati.

Cadangan dan pemulihan

Ekspor favorit, playlist, playlist pintar, rating, metadata khusus Luma, serta statistik lokal ke file JSON. File audio asli tidak disalin.

Cadangan memakai ID lagu lokal; sesudah memindahkan koleksi ke folder atau komputer lain, beberapa referensi playlist mungkin perlu dibuat ulang.

Privasi

Luma memutar file lokal. Tidak ada akun, iklan, pelacak, atau koneksi streaming. Riwayat, statistik, dan mix pribadi tersimpan di perangkat ini.
